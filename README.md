# BookLingo Landing Page

A beautiful, responsive landing page for **BookLingo** - the language learning app that lets you learn by reading books you love.

## Features

- Clean, literary-inspired design with warm parchment tones
- Interactive phone mockup showing the translation feature
- Smooth scroll animations and hover effects
- Fully responsive for mobile, tablet, and desktop
- Links directly to the App Store

## Running Locally

Start a local server:

```bash
cd /Users/fdema/Developer/personal/MyPassionWebsite
python3 -m http.server 8000
```

Then open http://localhost:8000 in your browser.

## About BookLingo

BookLingo is the most enjoyable way to learn a new language: simply by reading the books you love. Import any ebook in the language you're learning and get instant translations of words or full sentences into your native language.

**Features:**
- Import any EPUB ebook
- Instant word and sentence translations
- Vocabulary building with interactive study modes  
- AI-generated short stories for practice
- Dark/light reading themes
- Reading and study time statistics

**Available on:** iOS 18+, iPadOS, macOS, Apple Vision

**App Store:** https://apps.apple.com/se/app/booklingo/id6755432558
